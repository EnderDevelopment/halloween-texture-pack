# Halloween 2026 Texture Pack (Minecraft Bedrock / mobile)

A spooky Halloween 2026 texture and GUI pack for **Minecraft Bedrock Edition**, including mobile (Android / iOS) on **version 26.60**. This resource pack adds festive carved pumpkins, cobwebs, candy, and a custom Halloween main menu with a haunted graveyard scene, bats, and glowing pumpkins.

## Install

1. Convert each `assets/textures/*.svg` to `*.png` (16×16) and `assets/gui/halloween_menu.svg` to a `*.png` suited to your menu. You can do this with any SVG-to-PNG converter or image editor.
2. Put the files into a folder named `Halloween2026_HH`.
3. Zip that folder and rename the archive to `Halloween2026_HH.mcpack`.
4. Open the `.mcpack` on your device — Minecraft will import it as a resource pack.
5. Go to **Settings → Global Resources → My Packs** and activate it.

## Use

Once installed, the Halloween textures will apply to pumpkins, cobwebs, and the candy item in your world. The custom main menu art will appear when you launch the game. All textures are 16×16 for crisp pixel art matching Minecraft's style.

## Files

- `manifest.json` — Bedrock resource-pack manifest (format_version 2)
- `assets/textures/pumpkin_side.svg` — Carved pumpkin side face (16×16)
- `assets/textures/pumpkin_front.svg` — Carved pumpkin glowing front face (16×16)
- `assets/textures/pumpkin_top.svg` — Pumpkin top with green stem (16×16)
- `assets/textures/cobweb.svg` — Spider web texture (16×16)
- `assets/textures/candy.svg` — Halloween candy item (16×16)
- `assets/gui/halloween_menu.svg` — Halloween main-menu art with moon, bats, graveyard

## Note

This project stores every image as an **SVG**. Minecraft Bedrock expects raster textures, so each SVG above is the source you keep and edit; convert each one to PNG at the same size before bundling, or drop them into a supported texture-tool workflow.
